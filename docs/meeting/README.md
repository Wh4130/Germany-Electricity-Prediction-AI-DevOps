## How to use this folder

One file per meeting, named `YYYY-MM-DD.md` (e.g. `2026-10-28.md`), to keep the decisions and the notes of each meeting. Add a line to the list below when you add a file.

`ideas.md` is a personal notes file (ideas and open points, not decisions of the team). It is not committed, see `.gitignore`.

## Template

```
# Meeting YYYY-MM-DD

## Navigator
- [Discussion](#discussion)
- [Goals before next week](#goals-before-next-week)

## Discussion
Numbered topics, each with the decision and the reason.

## Goals before next week
One section per person, as a checklist.
- [ ] task
```
