## Discussion

### 1. Carnival feature: not built

Decision: the carnival feature is not built, the cost-benefit is too low.

- Carnival is not a public holiday, and there is no source that says which state gives a day off on which carnival day. It depends on the employer.
- We would have to assume a matrix of "state x day = share of people who do not work". That assumption is weak, and the expected gain is small.
- Details of the first check: [Not done / planned](../FEATURES.md#not-done--planned).

### 2. Industrial production index

- Two versions exist, with different data origins: WH's (Eurostat, all industry) and Chien-Yun's (Destatis GENESIS, energy-intensive industries).
- Decision: keep Chien-Yun's version. It is the more reasonable one, because it covers the energy-intensive industries and already aligns the values to the release date. WH's version is removed from the features.
- The alignment is needed: the value of the current period cannot be observed at prediction time. A value is used only from its publication date, which [production_index_pipeline.py](../../src/feature_engineering/production_index_pipeline.py) already does.
- WH looks for other leading economic indicators to use as features. They will be tested with an ablation later.
- Related: [Production index columns](../FEATURES.md#production-index-columns).
